# SHI Produksi v2

Sistem produksi PT. Sentra Herbal Internasional (Supabase + Cloudflare).

## Deploy

1. Upload **semua** file dari paket deploy ke Cloudflare Pages **atau** commit `index.html` penuh di repo ini.
2. File penting:
   - `index.html` (aplikasi utama)
   - `manifest.webmanifest`, `sw.js` (PWA)
   - `icon-192.png`, `icon-512.png`

## Status

- `manifest.webmanifest` + `sw.js` sudah di repo.
- Upload `index.html` lengkap dari paket `shi-produksi-pwa.zip` agar aplikasi jalan penuh.
